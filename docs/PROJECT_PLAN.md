## 执行摘要

**做什么**：在不依赖任何官方 API 的前提下，纯从浏览器页面实时抓取 Gate 平台 BTC 与 ETH 五分钟涨跌局的倍率序列与曲线形态，本地落库、统计挖律、建立可解释的级联预测模型，在高置信场景下给出"涨/跌/观望"方向结论，并以悬浮在浏览器页面上方的**决策弹窗**把信号即时送到下单者眼前。

**为什么这样做**：倍率变化序列是平台实时资金博弈的浓缩表达（第一信号），曲线形态为辅助，结算结果仅作标签；BTC 与 ETH 高度同源又时常背离，互为参考使信息量接近翻倍。系统按"能稳定抓、能省内存、能后台跑、能给可信概率"四件事设计：三通道识别防读错、三级存储与降采样防内存爆满、防节流参数与心跳保活支持后台常驻、级联模型加置信度校准把把握提到 80% 档。

**怎么做**：六层加横切运维的分层架构（页面识别→状态机→采集→存储→统计挖掘→预测置信度），配套实时计算引擎、命中/失败核算与信誉评分、异常局隔离、跟随与剩余时间机制，前端为置顶决策弹窗 + 八页面分析控制台，并预留真实市场 API 作趋势参考。前端另设"自动验证长跑"闭环：一键启停后系统持续抓取、持续复验、自主挖掘量化因子并重训模型，以滚动样本外高置信档命中率为唯一收敛判据逐轮迭代并全程留痕可回滚（第二十七章）。

**目标与边界**：目标是"高把握时出手"的短期局部优势，不承诺长期必胜——该类平台底层抽水使长期期望为负，故系统以模拟盘/纸面回测为默认模式并设硬止损。落地按 M0~M8 里程碑推进，验收以"零错位、命中≥78%、7×24 稳定、弹窗切后台不错位"等硬指标衡量。
